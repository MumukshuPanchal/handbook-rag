What happens when you ask

  1. The handbook is searched by meaning and by keyword, and the two lists are merged.
  2. A model writes the answer from the passages found, with a number after each statement. Code checks that every number names a passage that was sent.
  3. Or it declines with one fixed sentence when the passages do not hold the answer.
  4. A follow-up is rewritten first. With earlier questions, one request to the model turns "and in Finland?" into a question that stands alone.
  5. A stored answer is served again without a request, and names the question it was written for.
